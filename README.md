# Weekly Levels

Replaces the Featured by Weekly Levels, like if you're in GDLite.

**NOTE**: For showing the Weekly Levels title, you will need to use [BetterInfo](https://geode-sdk.org/mods/cvolton.betterinfo) for it.
**WARNING**: This mod deletes the classic Featured button! (Or replaces it by Weekly Levels of GDLite) You will no longer have access to the normal Featured if you install this mod.
